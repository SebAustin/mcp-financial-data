01 · The problem

Financial-services AI fails the same audit checklist

Every one of these is a quiet, expensive failure mode. This project treats all four as hard constraints — enforced in code and in CI, not in a style guide.

1

Wrong-source citations. The agent answers with a number, but the citation points at the wrong filing.

2

Silent fact drops. The agent omits a fact when the source doesn't support it — with no signal that anything was dropped.

3

Unscoped integrations. The MCP integration never validates JWT scopes per request.

4

Non-deterministic evals. The harness isn't replayable, so yesterday's regression is indistinguishable from a flaky judge today.

03 · Architecture

Every request is authenticated, cached, and traceable

Every EDGAR / FRED / Polygon / extractor response is keyed into a 24-hour SQLite cache — so eval runs are reproducible and the metered APIs aren't hammered.

04 · The centrepiece

The citation contract: cite the span, or drop the claim

The 10-K extractor calls Claude Sonnet 4.5 with the Anthropic Citations API. Its output is filtered through a contract no model output can bypass.

demoted uncited model output

"[INFERENCE] Apple may face increased regulatory scrutiny in the EU over App Store policies."

→ moved to notes, prefixed [INFERENCE] — never a fact.

shipped citation-grounded claim

"The Company's business depends on the timely receipt and successful integration of components from third-party manufacturers."

→ CitedClaim + ≥1 Citation span · AAPL 10-K FY2025 Item 1A

model output→ has Citations API span?→ span verbatim in source?→ CitedClaim ✓ ·else· dropped / [INFERENCE]

ADR 0003 · SEC 17a-4 / FINRA 4511 expect verifiable lineage from any model artifact to the source filing.

06 · Security

OAuth 2.1 — a resource server, never an IdP

Per MCP spec 2025-11-25, an authenticated MCP server is a resource server. It validates JWTs minted by an external IdP — it never mints them itself.

🎫 RFC 6750 validation

Full bearer-token validation: issuer, audience, expiry, signature against the configured JWKS. auth/oauth.py

🔒 Algorithm allowlist

PyJWT is pinned to an explicit algorithms= set — closing the alg=none and key-confusion attacks of RFC 8725. ADR 0005

🚪 Per-request gate

ASGI middleware authenticates every HTTP request to the server — a clean 401 with WWW-Authenticate on failure. ADR 0004

✓External IdP only — Auth0 / Authentik / Keycloak. No public keys hardcoded; embedding an IdP would widen the attack surface.
✓A dev-token CLI minter exists for local testing, gated on a local issuer URL so it can't be mistaken for production auth.
07 · Data discipline

Good-citizen clients: Fair Access, rate limits, caching

EDGAR, FRED, and Polygon share one design — because SEC Fair Access, a spend cap, and eval reproducibility all force it.

🪪 EDGAR Fair Access

Every SEC request carries a contact User-Agent; the process is rate-limited to ≤ 10 req/sec across all callers. ADR 0006

♻️ 24-hour cache

A shared SQLite response cache with 24h TTL — eval runs replay identically and the metered APIs aren't burned. tools/cache.py

🔁 Retries + backoff

Tenacity-backed exponential retry on 429 / transient errors — verified by tests asserting concurrency stays under the rate ceiling.

✓Spend cap. MAX_API_SPEND_USD is enforced inside the extractor and the eval harness — not just on a dashboard.
✓House rules. No requests, no print(), no subprocess(shell=True), no bare except — anywhere in the codebase.
08 · Proof, not vibes

A deterministic eval harness gates every change

Offline fixtures make CI free and replayable; a live path scores real filings. A paired LLM judge sits on top of deterministic metrics — never instead of them.

⚙️ exec-accuracy

Deterministic structural match of tool output vs. expected.

🔗 citation coverage

Share of facts carrying a valid citation — must equal 1.00 for tenk.*.

⚖️ Opus 4.7 judge

A five-axis rubric scored by Claude Opus 4.7, replayable per case.

💰 budget gates

10 · The stack

Modern, typed, async-first Python

🧩 Protocol layer

fastmcp + mcp on streamable HTTP, Starlette ASGI middleware, MCP spec 2025-11-25.

🌐 Data layer

httpx async clients, tenacity retries, a SQLite response cache, Pydantic v2 models throughout.

🤖 Intelligence layer

Anthropic SDK — Sonnet 4.5 extractor via the Citations API, Opus 4.7 as the eval judge.

🔐 Auth layer

authlib + PyJWT[crypto] for RFC 6750 resource-server validation against a JWKS.

📊 Observability

structlog structured logging — bound context on every tool call, no stray print().

🛠️ Tooling

uv for env + lock, ruff, mypy, pytest, pre-commit, Docker, GitHub Actions.
